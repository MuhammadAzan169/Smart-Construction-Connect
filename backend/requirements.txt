# =============================================================================
# Smart Construction Connect — BACKEND runtime dependencies
#
# This file is what RENDER installs. It is deliberately CPU/RAM-light so the
# service fits the free plan (512 MB RAM, no persistent disk):
#   • no PyTorch, no sentence-transformers, no FAISS, no EasyOCR
#   • semantic search uses an external embeddings API (EMBEDDINGS_* env vars)
#     and falls back to built-in BM25 keyword search when they are unset
#
# For LOCAL development also install requirements-local.txt, which adds the
# local models (SBERT + FAISS + OCR). `python app.py` at the repo root does
# that for you automatically.
# =============================================================================
